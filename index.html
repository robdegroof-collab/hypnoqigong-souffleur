Bluetooth-klikker testen

Koppel de klikker eerst via Android Bluetooth. Druk daarna op een knop: de ontvangen toets verschijnt hieronder. Gebruik bij voorkeur een klikker die pijltjes, spatie of Enter verstuurt.

Nog geen toets ontvangen.

Toetsen: pijl rechts / spatie / Enter = volgende; pijl links = vorige; pijl omhoog = herhaal; Escape = stop. De pagina moet actief zijn. Sommige mediaknoppen en camera-remotes sturen geen bruikbare toetsen naar Chrome.

Dit is een experimenteel prototype. Browser-spraakherkenning kan een externe dienst gebruiken; gebruik geen vertrouwelijke cliëntinformatie. Houd het scherm aan tijdens de test: Android kan webpagina's op de achtergrond pauzeren.
