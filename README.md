# HypnoQigong Souffleur

Experimental mobile teleprompter for spoken HypnoQigong sessions.

## Test

Open https://robdegroof-collab.github.io/hypnoqigong-souffleur/ on Android Chrome.

Version 0.2 supports keyboard/Bluetooth clicker controls, and optional experimental voice recognition.

Do not place private client information or confidential scripts in this public repository.
